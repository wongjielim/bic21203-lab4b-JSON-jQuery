# BIC21203-lab4b-JSON-jQuery

## Client-Side Scripting (JSON and jQuery)

### 1. Introduction
This project is developed as part of Lab 4b for the BIC21203 Web Development course. The purpose of this lab is to practise creating JSON data, retrieving and displaying JSON information using JavaScript, and manipulating HTML elements using jQuery.

### 2. Project Objectives
- Create and structure valid JSON data.
- Retrieve and parse JSON data using the JavaScript `fetch()` API.
- Display selected JSON information on a webpage.
- Understand and apply jQuery for DOM manipulation and event handling.
- Compare native JavaScript with jQuery.

### 3. Project Files

| File Name | Description |
|---|---|
| `books.json` | Stores information about two books, including their titles, authors, publication years, and genres. |
| `books.html` | Uses JavaScript `fetch()` to retrieve and display book information from the JSON file. |
| `jquery-dom.html` | Demonstrates jQuery methods for changing text, adding CSS classes, and handling button clicks. |

### 4. Technologies Used
- HTML5
- CSS3
- JavaScript
- JSON
- jQuery 4.0.0
- Visual Studio Code
- Live Server

### 5. How to Run the Project

1. Clone or download this repository to your computer.
2. Open the project folder using Visual Studio Code.
3. Install the Live Server extension if it is not already installed.
4. Right-click `books.html` and select **Open with Live Server**.
5. The webpage will retrieve and display the information from `books.json`.
6. To test Question 3, open `jquery-dom.html` using Live Server.
7. Click the button to test the jQuery click event.

**Note:** The HTML files should be opened through a local development server to ensure the `fetch()` function works correctly.

### 6. Conclusion
This lab provides practical experience in handling JSON data, retrieving information using JavaScript, and performing DOM manipulation using jQuery. It also helps develop a better understanding of client-side scripting and interactive web development.
